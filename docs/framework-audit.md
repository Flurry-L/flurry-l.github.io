# 博客功能与实现审查

审查日期：2026-11-13。范围包括页面、组件、浏览器交互、内容处理、构建和部署。

## 搜索入口的设计选择

本站顶部是简洁的导航和图标操作区，搜索、GitHub、主题切换统一使用 Tabler 的线性图标：相同的 24×24 画布、2 单位描边，以 20px 显示，放进 36px 按钮；使用无内边距的 Grid 容器居中，颜色和键盘焦点轮廓也共用。悬停只改变颜色，去掉倾斜放大。快捷键仍可使用，入口不再显示快捷键徽标。

实现保留 Pagefind 官方的触发器和弹窗，使用 `compact`、`hide-shortcut` 属性。Pagefind 样式放入 CSS 层，再由本站的共同按钮样式调整外观，避免用 `!important` 争抢样式优先级。

菜单、目录、返回顶部也改用 `@tabler/icons-vue`，移除另一套图标依赖。搜索与代码复制需要 CSS mask，直接保存同一版本 Tabler 的 SVG 和许可证，用官方图标变量替换搜索图案；没有添加图标转换构建流程。

这个选择参考了 [AstroPaper 的顶部搜索图标](https://github.com/satnaing/astro-paper/blob/main/src/components/Header.astro)，并使用 [Pagefind 官方触发器配置](https://pagefind.app/docs/components/modal-trigger/)。

## 中文、英文和数字混排

正文排版规则集中在 `src/styles/typography.css`，继续使用 Tailwind Typography；生成文案的格式化集中在 `src/lib/format.ts`。依据 W3C《中文排版需求》和 CSS Text，正文采用原生排版间隙；日期、字数、阅读时间和日历标签则使用 `Intl` 与 Pangu 生成带标准间距的显示文本：

- 全站使用原生 `text-autospace`，包括导航、标题、摘要、正文和元信息。先声明 `normal`，再声明带 `replace` 的规则：支持时将已有半角空格按自动间隙处理；仅支持基础属性的浏览器仍能为紧邻的中西文增加间隔。自动间隙不加入 DOM 文本，也不改变复制、搜索或文章锚点。
- `Intl.DateTimeFormat` 和 `Intl.NumberFormat` 负责日期、月份与数字本地化；Pangu 的纯字符串 API `spaceText` 负责生成文案的中西文间距。月份范围直接连接已有的起止月份标签，保持与月份选择框一致，避免 `formatRange` 在不同国际化数据版本下使用不同的月份格式。这些标签不再依赖浏览器的 `text-autospace` 支持，机器日期、URL 和 ID 保持原值。
- 正文在不支持自动间距的旧浏览器中保留原有显示；不额外扫描整页或改写 Markdown 源码。`replace`、标点压缩等能力作为渐进增强，不能保证所有浏览器表现完全一致。
- 保留中文行首、行尾禁则，正文使用 1.9 倍行高；支持时收紧行首标点并允许末尾标点悬挂。标题与段落分别使用 `text-wrap: balance` / `pretty` 改善断行。
- 正文数字使用比例宽度；日期元信息、归档、日历和表格中需要对齐的数字使用等宽数字。代码、键位提示、输入框与公式关闭自动间距，保留其自身排版。
- 使用 Markdown-it 官方维护的 `markdown-it-cjk-breaks` 处理中文段内软换行。英文单词间的换行仍分隔单词，显式硬换行和代码保持原有行为；文章、静态页、摘要与 RSS 共用这套解析规则。

成熟中文主题 [NexT 使用 Pangu](https://github.com/next-theme/hexo-theme-next/blob/master/_vendors.yml) 解决同类间距问题。本站复用其字符串处理能力，只处理明确的生成标签；正文采用原生 CSS，代码与公式保留原本的排版。写作时使用中文标点、英文与数字使用半角字符，词组内部保留英文所需空格；框架不自动改写作者的标点或单位。

## 正文间距与公式修复

`MarkdownContent` 原来的模板根注释被编译为 Fragment，导致生产运行时无法将外部的 `mt-8` 类传给正文元素；SSR 输出却包含该类，所以站内跳转与刷新相差一段间距。将 ESLint 说明移入脚本，保留单一元素根节点，恢复 Vue 标准属性透传；回归测试用生产 Vue 运行时执行该组件的客户端编译模板。

数学渲染原先有两个 KaTeX 版本：插件内嵌 0.17，页面样式来自 0.18。改用官方 `@mdit/plugin-katex-slim`，让渲染与 CSS 共用项目里的同一份 KaTeX；使用兼容当前 Markdown-it 14 的 1.0.x 系列。按 [KaTeX 维护者建议](https://github.com/KaTeX/KaTeX/discussions/2942)，将横向滚动移到插件已有的 `.katex-block` 外层，让公式保留自身的排版盒与上下留白，避免裁切伸出的笔画。没有改写 TeX、添加符号补丁或替换渲染引擎。

## 保留的代码与校验

日期分组、相邻文章查找、日历月份模型和 Clipboard API 适配都是小而明确的业务代码。继续使用 JavaScript 标准能力，避免为了消除几行循环而引入新的抽象。

同样保留坏的发布时间报错、图片构建失败后清除失败缓存、复制权限被拒绝后的反馈，以及等待组件挂载的检查。这些对应实际的输入错误、浏览器行为或生命周期；没有添加重试链、容错状态机或静默吞错。

## 实现依据

- [Pagefind：触发器属性](https://pagefind.app/docs/components/modal-trigger/)与[主题变量](https://pagefind.app/docs/css-variables/)。
- [VueUse：useDark](https://vueuse.org/core/usedark/)负责系统偏好和持久化，[useEventListener](https://vueuse.org/core/useeventlistener/)负责监听器生命周期。
- [sitemap.js：通过 SitemapStream 生成 XML](https://github.com/ekalinin/sitemap.js)。使用与项目现有 Node.js 最低版本兼容的 9.x。
- [VitePress 目录实现](https://github.com/vuejs/vitepress/blob/v1.6.4/src/client/theme-default/composables/outline.ts)采用缓存节点和降低滚动计算频率的方式。
- [Tabler Vue 图标](https://docs.tabler.io/icons/libraries/vue)包含 UI 与品牌图标，按需导入组件。
- [W3C 中文排版需求：中西文混排](https://www.w3.org/TR/clreq/#mixed_text_composition_in_horizontal_writing_mode)与 [CSS Text 4：text-autospace](https://www.w3.org/TR/css-text-4/#text-autospace-property)说明间隙与复制文本的关系；[MDN 兼容性说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-autospace)用于判断渐进增强范围。
- [Markdown-it CJK breaks](https://github.com/markdown-it/markdown-it-cjk-breaks)处理东亚文字之间的软换行，不自制 token 改写插件。

## 验证

运行代码检查、类型检查、格式检查、全量测试和生产构建；另核对生成页面、RSS、sitemap、Pagefind 索引、404 产物及旧文章锚点。主题测试覆盖系统偏好变化、用户选择和深色模式初始化；Markdown 测试覆盖静态页与文章共用资源、内容切换后的复制和键盘图片访问；搜索测试覆盖隐藏快捷键提示后的实际快捷键、关闭与路由跳转。

混排测试覆盖中文软换行、英文换行、显式硬换行、行内代码、代码块和摘要。CSS 兼容性通过标准资料与构建产物核对；本轮没有使用浏览器做视觉验收。

主题回归测试直接挂载顶部导航，连续点击实际按钮，验证两次来回切换后的页面主题和按钮名称；避免只测试包装过的回调而漏掉模板传入鼠标事件的问题。VueUse 切换函数的无参调用在模板中明确写为 `toggleTheme()`。

生成文案测试同时检查站点时区、数字分组、日期与阅读信息的实际组件输出、日历月份范围和无障碍标签。公式回归测试读取重要性采样原文，核对四个独立公式使用同一份 KaTeX 渲染，且没有解析错误。

本轮结果：56 项测试、ESLint、类型检查、格式检查和生产构建通过；生成 25 个页面、12 条 RSS、24 条 sitemap URL、13 个搜索索引页面。既有 124 个文章和日历锚点全部保留，搜索组件继续按需加载。
